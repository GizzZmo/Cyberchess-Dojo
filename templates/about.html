Cyberchess Dojo

An AI Training Arena — Stockfish (The Teacher) vs. a multi-agent LLM system (The Student)

What is Cyberchess Dojo?

Cyberchess Dojo is an automated chess training pipeline where a classical chess engine (Stockfish) and a large language model (LLM) compete against each other game after game. Every game is recorded as a PGN file. The long-term goal is to use this ever-growing dataset to fine-tune the LLM so that it learns from Stockfish's superior play — a student being trained by a grandmaster.

The system is driven by a multi-agent AI orchestrator that selects the right specialist for each phase of the game: opening theory, tactical calculation, positional strategy, or endgame technique.

Key Features

🤖
Multi-Agent LLM System

Four specialised agents (Opening, Tactical, Positional, Endgame) collaborate via an AI orchestrator.

🎓
Stockfish Teacher

Configurable skill level (0–20) lets you pitch the AI against anything from a beginner to a grandmaster.

📈
Elo Tracking

FIDE-formula Elo ratings are calculated and persisted after every game, so progress is measurable.

🧪
Fine-tuning Pipeline

Convert accumulated PGN games into JSONL datasets compatible with OpenAI, Vertex AI, and HuggingFace.

🌐
Live Web Dashboard

Real-time board visualisation, Elo history chart, and game log — all in the browser.

🔌
Multi-Provider LLM

Swap between Google Gemini, OpenAI GPT-4o, and Anthropic Claude with a single flag.

How It Works

Two players face each other on every board:

RoleEngineColour
🎓 TeacherStockfish (classical engine)White
🤖 StudentLLM via AI OrchestratorBlack

The orchestrator analyses the board position, detects the game phase, and routes control to the most suitable agent. When two agents propose different moves, the orchestrator makes a third LLM call — acting as a grandmaster arbitrator — to synthesise a final decision.

Getting Started

Prerequisites

RequirementVersionNotes
Python≥ 3.103.10, 3.11, and 3.12 are tested in CI
Stockfish≥ 15Must be installed separately; set path via STOCKFISH_PATH
LLM API key—Gemini (default), OpenAI, or Anthropic — see LLM Providers

Installation

# 1. Clone
git clone https://github.com/GizzZmo/Cyberchess-Dojo.git
cd Cyberchess-Dojo

# 2. Install Python dependencies
pip install -r requirements.txt
⚠️ Stockfish is not included in the Python dependencies. Download it from stockfishchess.org and note the path to the binary.

Running the Arena

Single Game

python cyberchess.py

Loop Mode

Play multiple games back-to-back. Each game is appended to training_data.pgn with a Round header. The AI's Elo rating is updated after every game. 

# Play 10 games at Stockfish skill level 5
python cyberchess.py --games 10 --skill 5

# Ramp up difficulty
python cyberchess.py --games 20 --skill 10

LLM Providers

All three providers are accessed through the unified llm_adapter.py interface. The agents and orchestrator work identically regardless of which provider is selected.

Google Gemini (default)

export GOOGLE_API_KEY="your-key"    # https://aistudio.google.com/app/apikey

python cyberchess.py                            # gemini-1.5-flash (default)
python cyberchess.py --model gemini-1.5-pro

OpenAI GPT-4o

pip install openai
export OPENAI_API_KEY="your-key"

python cyberchess.py --llm openai
python cyberchess.py --llm openai --model gpt-4o-mini

Anthropic Claude

pip install anthropic
export ANTHROPIC_API_KEY="your-key"

python cyberchess.py --llm claude
python cyberchess.py --llm claude --model claude-3-haiku-20240307

Architecture

AI Agents

Agents live in the agents/ package. Each agent is a focused LLM persona with a domain-specific system prompt. They all share agents/base_agent.py, which provides:

  • Retry logic (exponential back-off on API errors)
  • UCI move extraction via regex
  • Random-move fallback when no valid UCI move can be parsed
AgentFileExpertise
OpeningAgentagents/opening_agent.pyDevelopment, centre control, castling
TacticalAgentagents/tactical_agent.pyChecks, captures, forks, pins, skewers
PositionalAgentagents/positional_agent.pyPawn structure, piece activity, weak squares
EndgameAgentagents/endgame_agent.pyKing activity, pawn promotion, technique

Orchestrator

orchestrator.py implements ChessOrchestrator, which routes board states to the right agent based on the current game phase:

Game PhaseConditionAgents Used
OpeningMoves 1–10OpeningAgent only
Endgame≤ 6 non-pawn pieces remainEndgameAgent only
Tactical middlegameAny check availableTacticalAgent → PositionalAgent
Quiet middlegameNo checks availablePositionalAgent → TacticalAgent

When two agents propose different moves, the orchestrator issues a third LLM call — acting as a grandmaster arbitrator — to synthesise a final decision.

LLM Adapter

llm_adapter.py exposes a single LLMAdapter class. Select the provider at instantiation time; all agents and the orchestrator call only adapter.generate(prompt), making the underlying model completely interchangeable.

Elo Tracking

After every game, elo_tracker.py calculates the AI's new Elo rating using the standard FIDE formula with a K-factor of 32.

  • Stockfish Skill → Elo mapping (community benchmarks): Skill 0 ≈ 800 · Skill 5 ≈ 1500 · Skill 10 ≈ 2000 · Skill 20 ≈ 3200
  • Results are appended to elo_history.json and persist across runs.
  • The AI starts at Elo 1200 if no history file exists.

Web Dashboard

The dashboard provides a live browser view of the board, Elo history chart, and game log.

# Terminal 1 — run the arena with live state output
python cyberchess.py --games 5 --dashboard

# Terminal 2 — start the dashboard server
python dashboard.py

# Open in browser
# http://127.0.0.1:5000

The board updates automatically every 2 seconds. Custom host/port:

python dashboard.py --host 0.0.0.0 --port 8080

Fine-tuning Pipeline

Convert the accumulated PGN games into a JSONL fine-tuning dataset with finetune_pipeline.py: 

# Default: training_data.pgn → finetune_data.jsonl (Black's moves only)
python finetune_pipeline.py

# Include both colours
python finetune_pipeline.py --all-moves

# Custom paths
python finetune_pipeline.py --input my_games.pgn --output dataset.jsonl

# Print statistics only (no file written)
python finetune_pipeline.py --stats

# Include per-position metadata in the output
python finetune_pipeline.py --metadata

Each line of the output is a JSON object:

{
  "prompt": "You are a chess expert playing as Black.\nCurrent board position (FEN): ...\nLegal moves: e7e5, d7d5, ...\n\nChoose the best move ...",
  "completion": "e7e5"
}

The format is compatible with:

  • OpenAI fine-tuning API (openai.fine_tuning.jobs.create)
  • Google Vertex AI supervised tuning
  • Hugging Face datasets / trl SFT trainer

CI / Workflow

The CI workflow runs on every push and pull request to main/master against Python 3.10, 3.11, and 3.12:

  1. Install — pip install -r requirements.txt + flake8
  2. Syntax errors — flake8 --select=E9,F63,F7,F82 (hard fail)
  3. Style warnings — flake8 --exit-zero --max-line-length=120
  4. AST parse check — Verifies the script can be parsed without executing it

FAQ

How do I install Stockfish on Ubuntu?

sudo apt-get install stockfish
which stockfish   # → /usr/games/stockfish
export STOCKFISH_PATH="/usr/games/stockfish"

How do I install Stockfish on macOS?

brew install stockfish
which stockfish   # → /opt/homebrew/bin/stockfish
export STOCKFISH_PATH="/opt/homebrew/bin/stockfish"

How do I install Stockfish on Windows?

Download the Windows binary from stockfishchess.org, extract it, and set: 

$env:STOCKFISH_PATH = "C:\path\to\stockfish.exe"

The LLM sometimes plays illegal moves — why?

LLMs are not inherently chess-aware. The base agent retries up to 3 times to parse a valid UCI move from the response. If all retries fail, a random legal move is played as a fallback so the game always continues. Increasing --best-of-n can reduce the frequency of illegal outputs.

Can I use a local / self-hosted LLM?

Not out of the box, but you can extend llm_adapter.py with a new provider class that wraps any OpenAI-compatible API (e.g. Ollama, LM Studio, or vLLM) and add it to the provider registry.

Where is the fine-tuning dataset saved?

By default to finetune_data.jsonl in the project root. Override with --output path/to/file.jsonl.

How do I reset the Elo history?

Delete or rename elo_history.json. The tracker will start from Elo 1200 on the next run.

How do I contribute?

Read CONTRIBUTING.md and open a pull request. Use the PR template.
